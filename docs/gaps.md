# Where DesignCraft falls short of InDesign

Note series (#2871) now provide independent numbering/styles and column-foot or margin placement. Margin notes align with their references, stack by page side across ordinary and anchored hosts, and report overflow. Stacking uses displayed cross-reference and running-header context. Running-header source pages use resolved references. Option changes invalidate table-cell note layouts. Hidden containers release their stack space. Indexed wrap neighbours retain stacked-margin host placements and displayed running-header/xref text, and follow host, stack or text-source edits. PDF exports retain notes outside the host frame's page. Native files retain the series; deletion resets embedded memberships before ID reuse. Pending continuations advance using their own series options before a later reference moves on. IDML writes all notes using its one footnote setup with a warning for additional series or margin placement, including notes in table cells. Anchored commentary streams (#2872) fit first parts on their anchor pages, route continuations independently of the body thread, and report stream overflow separately from body overset. Inset-column geometry and stream catchwords remain #2873. Continued-note parts replay their original page context; page-number markers within a paragraph spanning pages still use the paragraph-start page (#2886).
